PokemonConquest Like

Technologies Used

Description

Our project is a Java-based PC adaptation of the game Pokémon Conquest, inspired by the famous Fire Emblem video game series. The game supports two players, with each player having their own game window.

Developed as part of a team of 2.

My Contributions

  • Implemented the attack range system.
  • Developed the combat system and the highlighting of attackable tiles.
  • Implemented status effects (poison, burn, etc.).
  • Created the attack information system.
  • Designed the attack and Pokémon databases.
  • Implemented terrain generation and different tile types.
